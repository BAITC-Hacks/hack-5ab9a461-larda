# Larda — интерактивный MVP

Кликабельный frontend-прототип для AI-хакатона. Работает на mock-данных и не требует backend.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Demo flow

1. Нажмите «У меня есть бизнес-задача».
2. Нажмите «AI, помоги сформулировать» и последовательно сохраните три ответа.
3. Откройте готовую карточку и опубликуйте задачу.
4. В каталоге откройте первую задачу и отправьте предложение команды.
5. На экране выбора команд вручную нажмите `Accept` или `Reject`.

Readiness score, публикация, каталог, отклик и выбор команды реализованы локальным состоянием. Позднее mock-данные в `src/App.tsx` можно заменить REST-вызовами без изменения UX-логики.
