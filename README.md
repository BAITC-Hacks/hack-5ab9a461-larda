## 🎯 Проблема (The Problem)

Малый и средний бизнес (МСБ) регулярно сталкивается с практическими задачами, которые идеальны для выполнения студенческими командами. Однако владельцам бизнеса сложно сформулировать задачу в виде понятного технического задания.

Предприниматель говорит:
> «Мы хотим использовать ИИ, чтобы поднять вечерние продажи в кофейне».

Для студенческой команды этой информации недостаточно, чтобы приступить к работе. При этом бизнес не всегда владеет технической терминологией, не знает, какие данные предоставить, и как корректно оценить студенческое предложение.

**Larda устраняет этот разрыв.**

---

## ✨ Что мы создали (What We Built)

**Larda (ChallengeBridge)** — интерактивная платформа, соединяющая бизнес и студенческие команды.

1. **Интервью с ИИ**: Бизнес описывает проблему простыми словами.
2. **Уточнение дефицита информации**: ИИ определяет недостающие контексты (данные, ограничения, критерии успеха) и задаёт последовательные уточняющие вопросы.
3. **Структурированная задача**: Ответы превращаются в понятное студентам ТЗ.
4. **Прозрачный Task Readiness Score**: Программа детерминированно рассчитывает готовность задачи от 0 до 100%.
5. **Каталог и отклики**: Студенты находят опубликованные задачи с высоким баллом готовности и отправляют отклик своей команды.
6. **Ручной выбор**: Бизнес просматривает отклики и вручную выбирает команду для работы.

## 🎬 Демонстрационный сценарий (Demo Flow)

```text
Проблема бизнеса (ввод)
          ↓
ИИ-анализ и поиск пробелов
          ↓
Уточняющие вопросы (3 шага)
          ↓
Формирование карточки задачи
          ↓
Оценка готовности (Readiness Score ≥ 70%)
          ↓
Публикация в каталоге
          ↓
Просмотр задачи студентами & Отклик команды
          ↓
Принятие / отклонение отклика бизнесом
```

### Пошаговый порядок проверки (Walkthrough)

1. **Выбор роли**: Нажмите «У меня есть бизнес-задача».
2. **Формирование задачи**: Нажмите «AI, помоги сформулировать» и последовательно ответьте на уточняющие вопросы (сохраните три ответа).
3. **Оценка и публикация**: Проверьте ростовые метрики readiness score в готовой карточке и нажмите «Опубликовать».
4. **Отклик команды**: Перейдите в Каталог задач, откройте опубликованную задачу и отправьте предложение от имени студенческой команды.
5. **Выбор исполнителя**: На экране управления задачей бизнеса просмотрите поступившие отклики и нажмите `Accept` (Принять) или `Reject` (Отклонить).

## 🤖 Как работает ИИ (AI Integration)

ИИ в Larda — это не просто чат-бот, а адаптивный структуризатор информации.

### Схема обработки:
1. **Business Input**: «У нас кофейня. Вечером падают продажи, хотим поднимать выручку».
2. **AI Gap Detection**: ИИ определяет отсутствие полей `data`, `successCriteria`, `constraints`.
3. **Clarification**: ИИ генерирует 3 конкретных вопроса бизнесу.
4. **Challenge Generation**: По завершении ответов ИИ формирует структуру задачи в формате JSON:
   ```json
   {
     "title": "Увеличение вечерних продаж кофейни",
     "context": "Снижение потока клиентов после 18:00",
     "users": "Посетители кофейни",
     "data": "История продаж за 3 месяца",
     "expectedResult": "Рабочий прототип системы рекомендаций",
     "successCriteria": "Рост вечерней выручки минимум на 10%",
     "constraints": "Срок реализации 2 недели"
   }
   ```

> ⚠️ **Важно**: ИИ помогает сформулировать задачу, но окончательное решение о публикации и выборе команды всегда остается за человеком.

## 📊 Прозрачный Readiness Score (Оценка готовности)

Балл готовности задачи **не придумывается ИИ**, а рассчитывается детерминированным алгоритмом приложения, что гарантирует 100% прозрачность и объяснимость:

| Категория | Вес (Баллы) | Описание |
| :--- | :---: | :--- |
| **Контекст и потребность** | 20 | Четкость описания бизнес-проблемы |
| **Данные и материалы** | 20 | Наличие исходных данных для работы |
| **Ожидаемый результат** | 15 | Понимание финального артефакта |
| **Критерии успеха** | 15 | Измеримые показатели успешности |
| **Ограничения** | 10 | Сроки, технологии, ресурсы |
| **Целевая аудитория** | 10 | Понимание конечных пользователей |
| **Формат коммуникации** | 10 | Наличие контактов и регулярность связи |
| **ИТОГО** | **100** | **Публикация доступна от 70 баллов** |

## ⚡ Быстрый старт (Quick Start)

### Требования
* Node.js >= 20.0.0
* npm >= 10.0.0

### 1. Установка и запуск

```bash
# Клонирование репозитория (если требуется)
git clone <repository-url>
cd hack-5ab9a461-larda

# Установка зависимостей
npm install

# Запуск в режиме разработки (Vite)
npm run dev
```

После запуска откройте адрес, выведенный Vite в консоли (обычно **`http://localhost:5173`**).

```bash
npm run build
```

## 🏗 Архитектура и стек (Tech Stack)

### Технологический стек
* **Frontend**: React 19, TypeScript 5, Vite 6
* **Маршрутизация**: React Router DOM (`react-router-dom` v7)
* **Стилизация**: Vanilla CSS с токенами дизайна (поддержка Dark Mode, Glassmorphism, smooth animations)

### Структура проекта
```text
src/
├── app/         # Маршруты, глобальная оболочка, провайдеры
├── domain/      # Чистые доменные типы, интерфейсы и бизнес-правила (без React/DOM)

└── shared/      # Общие UI-компоненты, CSS-токены, элементы анимации
```

## 🧪 Тест-кейсы (Test Cases)

1. **Неполная задача (Weak task)**:
   * *Ввод*: «Хотим поднять продажи ИИ».
   * *Результат*: Низкий readiness score, 3 уточняющих вопроса от ИИ.
2. **Заполненная задача (Complete task)**:
   * *Ввод*: Заполнены контекст, данные, результат, критерии и ограничения.
   * *Результат*: Readiness score ≥ 70%, активна кнопка «Опубликовать».
3. **Отклик студента (Proposal)**:
   * *Действие*: Студент отправляет идею, план и ссылку на решение.
   * *Результат*: Отклик моментально отображается в кабинете бизнеса.
4. **Выбор команды (Business Decision)**:
   * *Действие*: Бизнес выбирает `Accept` или `Reject`.
   * *Результат*: Обновляется статус отклика.
